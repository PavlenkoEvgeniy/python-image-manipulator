# Security Policy

## Supported versions

Security fixes are provided for the latest released version. The application is
a desktop tool, so users are encouraged to update to the newest release.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/PavlenkoEvgeniy/python-image-manipulator/security/advisories/new).
Do not open a public issue for an undisclosed vulnerability.

Include the affected version, operating system, a description of the issue, and
a minimal reproduction if possible. You can expect an initial response within a
few days.
